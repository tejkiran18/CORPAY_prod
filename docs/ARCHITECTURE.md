## 2. Request lifecycle

```
client ─▶ Next.js edge ─▶ /api/v1/*  route.js
  ─▶ request-id + pino logger
  ─▶ rate-limit  (per IP+route)
  ─▶ auth       (JWT verify → req.user)
  ─▶ tenant     (attach req.user.orgId as WHERE guard)
  ─▶ rbac       (require permission code)
  ─▶ zod validate body / params / query
  ─▶ controller ─▶ service ─▶ repo (Prisma)
  ─▶ audit writer (async, non-blocking)
  ─▶ unified response envelope
```

## 3. Modules & responsibilities

| Module | Responsibilities |
|--------|-------------------|
| **Identity** | Password + JWT auth, sessions, forced logout, role/permission cache. |
| **Organization** | Tenants + org tree (BU/Department/CostCenter). |
| **Employee** | HRIS master, RBAC assignment, manager mappings. |
| **Project** | Project lifecycle, project-type registry. |
| **BusinessEvent** | Trips + client visits + conferences + onsite. |
| **PolicyEngine** | Compiles PolicyRules into an expression tree and evaluates against a `SpendContext`. |
| **SpendingRights** | Grant/consume/revoke rights; ACID counter maintenance. |
| **Budget** | Allocation + burn accounting. |
| **Transaction** | `validate()` → `commit()` in a single DB txn. Emits Audit + Notification + RiskEvent. |
| **Approval** | Generic N-step workflow engine. |
| **Merchant** | Merchant + MCC directory, dedup, verification. |
| **Risk** | Rule-based + ML-lite scoring, feeds RiskEvent. |
| **Notification** | Inapp/email/SMS/push emitter (async). |
| **Analytics** | KPI + rollups + monthly closure + cost-centers. |
| **AI** | Emergent LLM Forecast + Policy Coach. |
| **Audit** | Immutable log writer (INSERT-only role at DB level in prod). |
| **Admin** | Seed, reset, health, migrations. |

## 4. Non-functional guarantees

- **ACID payment path**: `SELECT … FOR UPDATE` on the SpendingRight row, insert Transaction, update counters, all in one `prisma.$transaction(async tx => …)` at serializable isolation.
- **Multi-tenant hard guard**: `tenant` middleware injects `organizationId` into every Prisma where-clause via a shared helper `withTenant(where)`.
- **Zero-trust FK**: every mutation validates that all referenced FKs belong to the requester's org.
- **N+1 prevention**: repositories use Prisma `include` explicitly per use-case, never generic getters.
- **Pagination**: cursor by `id` for hot lists (`transactions`, `audit_logs`); offset elsewhere. Default page size 50, max 500.
- **Logging**: structured pino JSON with `req_id`, `org_id`, `route`, `duration_ms`, `db_ms`.

## 5. What we will remove

- `mongodb` package.
- Any `stripId` / `_id` code paths.
- The single-file `/app/app/api/[[...path]]/route.js` handler once `/api/v1/*` is at parity.

(Legacy handler will be kept as a thin redirect that returns `301 → /api/v1/*` for one release before being deleted.)
